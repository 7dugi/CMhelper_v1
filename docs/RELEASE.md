# 출시 및 배포 관리

문서에만 설계된 기능을 배포 완료로 간주하지 않으며, 실제 테스트/검증 근거에 따라 상태를 구분합니다.

## v0.4.1 (내부 검증 완료 / 베타 배포 준비)
- **상태:** `[구현 완료]` / `[로컬 테스트 완료]` / `[exe 빌드 테스트 완료]` / `[운영 환경 배포 미완료]`
- **목표:** 기초 발송 안정성 확보 및 엔터프라이즈 B2B SaaS 급의 복구 체계 도입.
- **수동 검증 완료된 기능:**
  - 예약 등록 및 예약 시간 DB 저장.
  - Agent 수동 실행 후 예약 작업 대기열 조회 및 처리.
  - `Heartbeat` 기반 고아 작업(Orphan Task) 탐지 및 `RECOVERY` 전이.
  - 발송 실패 시 재시도 카운트 상한(2회) 로직.
  - 에이전트 로컬 로그 분리 및 이름 마스킹(PII 제거).
  - PyInstaller `.exe` 빌드본에서 카카오톡 프로세스 인식 및 클립보드 발송 정상 동작.
- **미완료 / 계획 단계 (Planned):**
  - **자동 예약 발송:** 예약시간 자동 감지, 상시 실행 Background Agent (Windows 서비스 등).
  - 카나리아(Canary) 자동 테스트 파이프라인 구동 및 모니터링 시스템 구축.
  - 다중 에이전트 동시 접근 시 SQLite 락(Atomic Lock) 동시성 한계 스트레스 테스트.
- **알려진 이슈 (Known Issues):**
  - 클립보드 사용 시 OS 백그라운드 환경과 미세한 경합 발생 가능성. 재시도 로직으로 방어 중.
