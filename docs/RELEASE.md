# 출시 및 배포 관리

## v0.4.1 (현재 진행 중 / 상용 릴리즈 대기)
- **목표:** 엔터프라이즈 B2B SaaS 급의 안정성, 트래킹 시스템, 그리고 장애 복구 체계 적용 완료.
- **완료:**
  - `Heartbeat` 기반 고아 작업(Orphan Task) 복구 스케줄링.
  - `Atomic Lock`을 통한 메시지 중복 발송 차단.
  - 최대 2회 `RECOVERY` 상태 전환 재시도.
  - 에이전트 일자별 자동 로그 로테이션 및 이름 마스킹 보안 처리.
  - 프론트엔드 예약 발송 Auto-polling 연동 완료.
  - 로컬 PyInstaller 에이전트 빌드(`dist/agent.exe`) 검증 완료.
- **미완료:**
  - 실제 카나리아(Canary) 자동 테스트 파이프라인 구동 및 모니터링 시스템 구축.
- **알려진 이슈 (Known Issues):**
  - 클립보드 사용 시 OS 백그라운드 환경과 미세한 경합이 여전히 발생할 수 있으나, 재시도(`RECOVERY`) 로직으로 방어하고 있음.
- **배포 여부:** V4.1 내부 빌드 완료 및 적용.
