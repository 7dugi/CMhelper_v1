# 변경 이력 (Changelog)

모든 주요 변경 사항은 이 문서에 기록됩니다. 기능은 실제로 코드에 구현되고 안정성이 검증된 것만 `Added`, `Changed`, `Fixed`, `Security`에 기록합니다.

## [v0.4.1] - 2026-08-05
기초 1:1 대량 발송의 고도화 및 엔터프라이즈 장애 복구 시스템 로컬/빌드 테스트가 완료된 버전입니다.

### Added
- 예약 등록 기능 및 예약 작업 DB 저장 연동.
- Agent 수동 실행 후 예약 작업 대기열을 불러와서 처리하는 기능.
- `Heartbeat` 송수신 기반 에이전트 생존 확인 체계.
- 에이전트 비정상 종료 시 고아 작업(Orphan Task) 탐지 및 `RECOVERY` 전환 로직.
- 최대 2회 `RECOVERY` 상태 전환 재시도 카운트 상한(Retry Limit) 로직.
- 감사 로그(Audit Log) 파일 분리 저장 및 일자별 로테이션 기능.
- 고객 이름 첫/끝 글자 마스킹 및 PII(연락처/메시지 원문) 미기록 보안 규칙.

### Verified (수동 테스트 완료)
- 로컬 Python 실행 테스트 완료.
- PyInstaller `.exe` 빌드 실행 테스트 완료 (카카오톡 창 제어 및 클립보드 정상 작동).
- 예약 발송(수동 실행 기반) 테스트 완료.
- 강제 종료 시뮬레이션을 통한 Recovery 복구 테스트 완료.
- 파일 로그 기록 및 보안 마스킹 정상 출력 테스트 완료.

### Planned (향후 계획)
- Background Agent (Windows 서비스 지원).
- 사용자가 에이전트를 켜두지 않아도 윈도우 백그라운드에서 항상 실행되는 체계.
- 예약시간 자동 감지 및 완전 무인 자동 예약 발송.
- 다중 에이전트 동시 구동 시 SQLite `locked_by` 로직(Atomic Lock)의 완벽한 락 경합 방지 스트레스 테스트.

## [0.1.0] - 2026-07-16
기초 기능 로컬 테스트가 완료된 버전입니다.

### Added
- 카카오톡 데스크톱 프로세스 인식 및 채팅방 진입 기능 구현 (`pywinauto`).
- 채팅방 이름과 발송 대상명 일치 여부 1차 검증(Final Validation) 기능.
- `pyperclip` 클립보드 경유 방식의 텍스트 및 이미지 분리 전송 기능.
- 백엔드(FastAPI) 기본 고객(Customer) 및 발송 큐(MessageTask) 생성 API 연동.
