# 리스크 관리 대장 (RISK REGISTER)

- **R-001**
  - **위험:** 카카오톡 PC버전 UI 전면 개편
  - **영향:** UIAutomation(pywinauto) ID 변경으로 인한 발송 일시 중단
  - **대응:** OpenCV 기반의 이미지 매칭 백업 경로 상시 유지
  - **상태:** 모니터링 중

  - **위험:** Supabase 클라우드 DB 서버 장애
  - **영향:** 에이전트가 발송 명단을 불러오지 못함
  - **대응:** 로컬 SQLite에 큐(Queue) 캐싱 저장 로직 구현
  - **상태:** 미구현
