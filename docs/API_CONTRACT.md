# API 통신 규약 명세서

웹 대시보드와 로컬 에이전트 간의 통신 스펙을 정의합니다.

## 1. 통신 방식 (초안)
- 로컬 에이전트가 N초(예: 30초)마다 웹 백엔드를 Polling 하여 발송 대기 큐 확인.
- 보안: JWT 토큰 기반 인증 사용 예정.

## 2. API 엔드포인트 설계 (예시)
### [POST] /jobs
- **역할:** 웹에서 에이전트로 작업 지시
- **Request:** `{ "customer_id": 1, "message": "안녕하세요" }`

### [POST] /result
- **역할:** 에이전트가 웹으로 발송 결과 보고
- **Request:** `{ "job_id": 1, "status": "SUCCESS" }`
